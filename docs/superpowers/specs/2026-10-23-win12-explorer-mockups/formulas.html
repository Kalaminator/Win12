Formulas — files are rows, properties are columns

Like Excel: every file or folder is one row. A formula runs once for every row, so the loop is automatic. For real loops there is a Script mode, like VBA. Both only make a plan; nothing changes until you press the button.

Level 2 — Script (VBA-like loops)
For Each f In Files("~/Downloads", Subfolders:=True)
  If f.Ext = "pdf" And f.Contains("invoice") Then
    f.MoveTo "~/Documents/Invoices/" & YEAR(f.Modified)
    f.Tag "Invoice", "Orange"
  ElseIf f.Size = 0 Then
    f.Trash
  End If
Next
